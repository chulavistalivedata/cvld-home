# CVLD embeddable homepage

Self-contained homepage widget for [chulavistalivedata.com](https://www.chulavistalivedata.com/). Edit `content.json` to change headlines, links, and the tip line. The page reads that file on every load.

## Live URL

After GitHub Pages is on for this repo:

https://chulavistalivedata.github.io/cvld-home/

## Embed in Google Sites

1. Open the Home page in Google Sites.
2. Insert → Embed → **By URL**.
3. Paste `https://chulavistalivedata.github.io/cvld-home/`
4. Set the embed width to full and height to about **980**.

If the host page allows a script (custom HTML), use `embed.html` so the iframe height can follow the content.

## How Grok updates it

Tell Grok what to change (a story, a live link, a button). It edits `content.json` or `index.html` in this repo. Refresh the Sites page after Pages rebuilds (usually under a minute).

Do not invent meeting outcomes or quotes. Keep support and social links accurate.
